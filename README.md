A teacher, a failed essay, and advice to begin with the truth the writer was avoiding, expressed in one sentence. The dependency-free program writes deterministic UTF-8 text using only the Node.js standard library.

## Run it

Requires Node.js 22.18 or later.

```sh
node main.ts
```

It writes the sentence to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
